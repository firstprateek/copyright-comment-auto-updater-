# Changelog

All notable changes to the **Copyright Comment Auto-Updater** extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-02-22

### Added

- Auto-update copyright years on file save
- Auto-insert copyright headers in JS/TS files when none exists
- Support for JavaScript, TypeScript, C++, MATLAB, XML, HTML, and CSS
- Test file detection and exclusion (filename, class name, comment-based)
- Configurable company name, comment templates, scan depth, auto-insert languages, and test file patterns
- Multi-root workspace support via resource-scoped settings
